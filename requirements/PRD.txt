Falah.ai — Product Requirements Document (PRD)
================================================

1. PRODUCT VISION
-----------------
Falah.ai is a general-purpose AI agent platform for live, real-time conversations.
Users build custom AI personas — investor VCs, enterprise clients, interview coaches,
onboarding guides, trainers, support agents, or anything they imagine — then go live
with them using real-time audio and screen sharing. After every session, the AI scores
performance and generates actionable feedback.

The platform is NOT limited to pitches or sales. Any conversation skill that benefits
from realistic practice with an intelligent counterpart is a valid use case.

Target: Google Gemini Live API Challenge
Models: Gemini 2.5 Flash (native audio + vision), Gemini Embedding 2 (context vectors)


2. TECH STACK
-------------

  - Python 3.12+, FastAPI, Uvicorn
  - SQLAlchemy (async) + asyncpg + PostgreSQL
  - Alembic (migrations), pgvector (semantic search)
  - google-genai SDK (Gemini Live API + Embeddings)
  - LiveKit Agents SDK (WebRTC media routing)
  - JWT + bcrypt auth, Google OAuth

Frontend:
  - React 19, Vite, TypeScript
  - Tailwind CSS v4
  - Zustand (state), React Router v7

Infrastructure:

  - PostgreSQL (with pgvector extension)
  - Docker + Docker Compose (deployment)


3. CORE FEATURES
----------------

3.1 Custom AI Agents (Personas)
  - Users create agents with: type, name, role, personality, focus areas, voice
  - Advanced settings: custom scoring criteria, behavior rules, opening message
  - 8 configurable AI voices (Puck, Charon, Kore, Fenrir, Aoede, Leda, Orus, Zephyr)
  - 7 starter templates: Investor VC, Enterprise Client, Onboarding Guide,
    Product Trainer, KT Specialist, Interview Coach, Support Agent
  - Community sharing: make agents public, discover others' agents, clone templates

3.2 Live Sessions (Real-Time Audio + Vision)
  - WebRTC-powered real-time audio via LiveKit
  - Screen sharing: AI agent sees user's screen (slides, docs, dashboards)
  - Voice Activity Detection controls video frame sampling:
    - 0.5 FPS while user speaks (captures important content)
    - 0.2 FPS during silence (reduces token usage)
  - Affective dialog: AI adapts tone to match user's vocal cues
  - Proactivity: AI speaks when appropriate (nudges during silence)
  - Barge-in support: user can interrupt the AI mid-sentence
  - Context window compression: triggers at 90K tokens, compresses to 45K

3.3 Session Scoring & Analytics
  - Post-session AI scoring via Gemini Flash
  - Default 5 scoring dimensions: Clarity, Objection Handling, Engagement,
    Context Awareness, Closing Strength (1-10 each)
  - Custom scoring: agents can define their own dimensions
  - AI-generated session summary (2-3 sentences)
  - Full transcript with timestamps (user + agent turns)
  - Session history with duration, scores, and status tracking

3.4 Context Intelligence
  - Upload documents (emails, transcripts, notes, briefs) per agent
  - Gemini Embedding 2 generates 3072-dim vectors for semantic search
  - AI synthesizes uploaded docs into a structured pre-call briefing:
    Key Concerns, Communication Summary, Decision Factors, Data Points
  - Briefing cached on persona record, refreshable on demand
  - Manual CRM notes injected at session start (max 1000 chars)

3.5 Adaptive Session History
  - Agent prompt includes most recent completed session's summary + score
  - Adaptive behavior rules: don't repeat, probe weak areas, escalate difficulty,
    introduce new angles, acknowledge improvement
  - Persona snapshot frozen at session creation for immutable scoring

3.6 Connectors (Planned)
  - Gmail, Google Docs, Slack, Salesforce CRM, HubSpot, Notion
  - Auto-import context from external sources into agent sessions
  - Status: Coming Soon (UI scaffolded, not yet functional)

3.7 Guided Onboarding
  - Voice-driven onboarding agent ("Falah") walks new users through setup
  - 4 steps: Welcome → Explore UI → Create First Agent → First Session
  - Screen-aware: agent sees user's screen and references visible elements
  - Auto-end at 4:15 with graceful wrap-up starting at 3:45
  - Returning users get personalized re-entry based on previous progress
  - Floating bubble UI that expands/collapses over main app

3.8 Authentication
  - Email/password registration with bcrypt hashing
  - Google OAuth (ID token verification)
  - JWT tokens (HS256, 7-day expiry)
  - Onboarding status tracked per user

  Explore Agents Tab → Create Agent (or pick from Community) →
  Pre-Flight Check (mic, speaker, context) → Start Live Session →
  Session Ends → View Scorecard + Transcript

  Sign In → Agents Page → Select Agent → Pre-Flight →
  Go Live (with session history adaptation) → Review Results

4.3 Community Flow
  Browse Community → Preview Agent → Use Template (clones to your agents) →
  or Start Session directly with a public agent

4.4 Live Session Flow

  Connecting overlay (4-step setup animation) →
  Split-screen: Screen Share (left) + AI Status (right) →
  "Agent Live" header with elapsed timer →
  End Session → Auto-redirect to session detail with scores

6. API ENDPOINTS
----------------

Auth (/api/v1/auth/)
  POST /register        — Create account
  POST /login           — Email/password login
  POST /google          — Google OAuth login
  GET  /me              — Current user info

Personas (/api/v1/personas/)
  GET    /              — List user's agents
  POST   /              — Create agent
  GET    /{id}          — Agent detail
  PATCH  /{id}          — Update agent
  DELETE /{id}          — Delete agent
  GET    /public        — Community agents (search, type filter)
  GET    /templates     — Starter templates

Sessions (/api/v1/sessions/)
  POST   /              — Create session record (ACTIVE)
  PATCH  /{id}          — Update session
  POST   /{id}/score    — Trigger AI scoring
  GET    /              — List sessions (filter by agent, limit)
  GET    /{id}          — Session detail

LiveKit (/api/v1/livekit/)
  GET /token            — Generate room token (persona_id, context, session_id)
  GET /onboarding-token — Generate onboarding session token

Context (/api/v1/context/)
  POST /upload          — Upload document (text + embedding)
  GET  /briefing        — Get/generate cached briefing for agent
  GET  /search          — Semantic search across documents

Onboarding (/api/v1/onboarding/)
  PATCH /progress       — Update onboarding step/status

Legacy WebSocket:
  /ws/pitch/{persona_id} — Direct Gemini Live streaming (pre-LiveKit)

8. AI AGENT ARCHITECTURE
-------------------------

8.1 Prompt Construction (_build_dynamic_prompt)
  Input: persona config + CRM context + briefing + session history
  Output: Full system prompt with sections:
    - Identity (name, role)
    - Core Personality
    - Focus Areas (label varies by type: "Investment Thesis", "Top Concerns", etc.)
    - Intelligence Dossier (briefing from docs + manual notes)
    - Session History (most recent, with adaptive rules)
    - Behavior Rules (5 defaults + custom)
    - Opening instruction

8.2 Gemini Live Configuration
  - Model: gemini-2.5-flash-native-audio
  - Response modalities: AUDIO only
  - Context window compression: 90K trigger → 45K target
  - Thinking budget: 128 tokens (minimal latency)
  - Affective dialog: enabled
  - Proactivity: enabled

8.3 LiveKit Agent Worker
  - Separate Python process from FastAPI server
  - Reads persona config from room metadata (no DB calls during session)
  - TranscriptRecorder captures turns (last 100, pruned)
  - VoiceActivityVideoSampler for adaptive screen capture
  - Heartbeat logger every 60 seconds
  - Shutdown callback: persist transcript, trigger scoring, generate summary

8.4 Onboarding Agent
  - Persona: "Falah" with Aoede voice
  - 4-step guided flow with step-specific prompts
  - Screen share detection triggers contextual guidance
  - 15-second silence nudge
  - Auto-end sequence: 3:45 warning → 4:00 goodbye → 4:15 hard stop


9. KEY ARCHITECTURAL DECISIONS
------------------------------

  - Room metadata pre-baking: All persona config, briefing, and session history
    embedded in LiveKit room metadata at token generation time. Agent worker
    reads directly — zero DB calls during live sessions.

  - Two-process model: FastAPI server + LiveKit agent worker run independently.
    Agent worker spawns isolated DB engine to avoid event loop conflicts.

  - Persona snapshots: Sessions freeze agent config at creation time.
    Scoring uses snapshot, not current config — resilient to edits.

  - Post-call scoring: Uses Gemini Flash (fast + cheap). Doesn't block session.
    Neutral fallback scorecard on error (all 5.0).

  - Token budget management: CRM notes capped at 1000 chars, briefing at 2000 chars,
    session history limited to 1 most recent. Video frames adaptively sampled.

  - Async throughout: FastAPI + asyncpg + LiveKit SDK — non-blocking I/O everywhere.
