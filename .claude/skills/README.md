# Workspace Skills

This directory contains skills specific to this workspace.

## How to add a new skill

1. Create a new folder for your skill, e.g., `my-custom-skill`.
2. Inside that folder, create a `SKILL.md` file.
3. Add YAML frontmatter to `SKILL.md` with the skill name and description.
4. Add markdown instructions for the skill.

## Example Structure

```text
.agent/skills/
└── my-custom-skill/
    ├── SKILL.md
    └── scripts/ (optional)
```
