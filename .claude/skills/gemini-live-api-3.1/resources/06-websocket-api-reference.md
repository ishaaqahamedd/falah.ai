# WebSockets API Reference

Source: https://ai.google.dev/api/live.md.txt
Fetched: 2026-03-29

---

The Live API is a stateful API that uses WebSockets.

## WebSocket connection

Connect to:

```
wss://generativelanguage.googleapis.com/ws/google.ai.generativelanguage.v1beta.GenerativeService.BidiGenerateContent
```

> **Note:** The URL is for version `v1beta`.

## Session configuration

The initial message sets the session configuration (model, generation parameters, system instructions, tools). Configuration cannot be updated while connected (except via session resumption).

```json
{
  "model": "string",
  "generationConfig": {
    "candidateCount": "integer",
    "maxOutputTokens": "integer",
    "temperature": "number",
    "topP": "number",
    "topK": "integer",
    "presencePenalty": "number",
    "frequencyPenalty": "number",
    "responseModalities": ["string"],
    "speechConfig": "object",
    "mediaResolution": "object"
  },
  "systemInstruction": "string",
  "tools": ["object"]
}
```

## Client messages

| Message | Description |
|---|---|
| `BidiGenerateContentSetup` | Session configuration (first message only) |
| `BidiGenerateContentClientContent` | Incremental content update |
| `BidiGenerateContentRealtimeInput` | Real time audio, video, or text input |
| `BidiGenerateContentToolResponse` | Response to a ToolCall from the server |

## Server messages

| Field | Description |
|---|---|
| `setupComplete` | Response to setup message |
| `serverContent` | Content generated by the model |
| `toolCall` | Function call request |
| `toolCallCancellation` | Cancel a previous tool call |
| `goAway` | Connection will soon terminate |
| `sessionResumptionUpdate` | Session resumption state update |
| `usageMetadata` | Token usage information |

## Key Types

### ActivityHandling

| Enum | Description |
|---|---|
| `START_OF_ACTIVITY_INTERRUPTS` | Start of activity interrupts model response (default) |
| `NO_INTERRUPTION` | Model response will not be interrupted |

### AutomaticActivityDetection

| Field | Type | Description |
|---|---|---|
| `disabled` | bool | If true, client must send activity signals manually |
| `startOfSpeechSensitivity` | enum | How likely speech is detected |
| `prefixPaddingMs` | int32 | Required speech duration before start-of-speech |
| `endOfSpeechSensitivity` | enum | How likely speech end is detected |
| `silenceDurationMs` | int32 | Required silence duration before end-of-speech |

### BidiGenerateContentClientContent

| Field | Type | Description |
|---|---|---|
| `turns[]` | Content | Content appended to conversation |
| `turnComplete` | bool | If true, start generation |

### BidiGenerateContentRealtimeInput

| Field | Type | Description |
|---|---|---|
| `audio` | Blob | Realtime audio input stream |
| `video` | Blob | Realtime video input stream |
| `text` | string | Realtime text input stream |
| `activityStart` | ActivityStart | Marks start of user activity (manual VAD) |
| `activityEnd` | ActivityEnd | Marks end of user activity (manual VAD) |
| `audioStreamEnd` | bool | Audio stream ended (e.g. mic off) |
| `mediaChunks[]` | Blob | **DEPRECATED** — Use `audio`, `video`, or `text` instead |

### BidiGenerateContentServerContent

| Field | Type | Description |
|---|---|---|
| `modelTurn` | Content | Model-generated content |
| `generationComplete` | bool | Model finished generating |
| `turnComplete` | bool | Model completed its turn |
| `interrupted` | bool | Client message interrupted generation |
| `groundingMetadata` | GroundingMetadata | Grounding metadata |
| `inputTranscription` | Transcription | Input audio transcription |
| `outputTranscription` | Transcription | Output audio transcription |

### BidiGenerateContentSetup

| Field | Type | Description |
|---|---|---|
| `model` | string | Required. Model resource name |
| `generationConfig` | GenerationConfig | Optional |
| `systemInstruction` | Content | Optional |
| `tools[]` | Tool | Optional |
| `realtimeInputConfig` | RealtimeInputConfig | Optional |
| `sessionResumption` | SessionResumptionConfig | Optional |
| `contextWindowCompression` | ContextWindowCompressionConfig | Optional |
| `inputAudioTranscription` | AudioTranscriptionConfig | Optional |
| `outputAudioTranscription` | AudioTranscriptionConfig | Optional |
| `proactivity` | ProactivityConfig | Optional |
| `historyConfig` | HistoryConfig | Optional |

### ContextWindowCompressionConfig

| Field | Type | Description |
|---|---|---|
| `slidingWindow` | SlidingWindow | Sliding-window compression mechanism |
| `triggerTokens` | int64 | Token count to trigger compression (default: 80% of context window) |

### HistoryConfig

| Field | Type | Description |
|---|---|---|
| `initialHistoryInClientContent` | bool | If true, server waits for initial ClientContent history before starting |

### RealtimeInputConfig

| Field | Type | Description |
|---|---|---|
| `automaticActivityDetection` | AutomaticActivityDetection | VAD config |
| `activityHandling` | ActivityHandling | What effect activity has |
| `turnCoverage` | TurnCoverage | Which input is included in user's turn |

### SessionResumptionConfig

| Field | Type | Description |
|---|---|---|
| `handle` | string | Handle from previous session (empty for new session) |

### SessionResumptionUpdate

| Field | Type | Description |
|---|---|---|
| `newHandle` | string | Handle for resumable state (empty if not resumable) |
| `resumable` | bool | Whether session can be resumed at this point |

### TurnCoverage

| Enum | Description |
|---|---|
| `TURN_INCLUDES_ONLY_ACTIVITY` | Only activity since last turn |
| `TURN_INCLUDES_ALL_INPUT` | All input since last turn including silence |
| `TURN_INCLUDES_AUDIO_ACTIVITY_AND_ALL_VIDEO` | Audio activity + all video |

### GoAway

| Field | Type | Description |
|---|---|---|
| `timeLeft` | Duration | Remaining time before connection terminates |

### UsageMetadata

| Field | Type | Description |
|---|---|---|
| `promptTokenCount` | int32 | Tokens in prompt |
| `responseTokenCount` | int32 | Tokens in response |
| `thoughtsTokenCount` | int32 | Tokens for thinking |
| `totalTokenCount` | int32 | Total tokens |
| `promptTokensDetails[]` | ModalityTokenCount | Per-modality prompt tokens |
| `responseTokensDetails[]` | ModalityTokenCount | Per-modality response tokens |

## Ephemeral Auth Tokens

Obtained via `AuthTokenService.CreateToken`. Use with `BidiGenerateContentConstrained`.

### AuthToken

| Field | Type | Description |
|---|---|---|
| `name` | string | The token itself (output only) |
| `expireTime` | Timestamp | When messages are rejected (default: 30 min) |
| `newSessionExpireTime` | Timestamp | When new sessions are rejected (default: 60 sec) |
| `uses` | int32 | Number of times token can be used (default: 1, 0 = unlimited) |
| `bidiGenerateContentSetup` | BidiGenerateContentSetup | Locked configuration |

> **Note:** Resuming a Live API session does not count as a "use".
